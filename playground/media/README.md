# playground media

Images for the playground desk. Everything is referenced from
`playground/case.html` (the `ITEMS` array), addressed from the site root as
`/playground/media/<file>`, not as a bare relative path: the document is
served at `/playground/case.html`, so a relative one resolves a directory
too deep and 404s.

The dashed "drop in a file" slots are gone. Add an image here, then add a
`photo` item pointing at it.

## a rule this desk follows

Nothing that belongs to a live case study lives here — no Trove, Skrimp,
Menzo, MyAuntie or Equinox media. Those projects have their own pages.
This is only the work that never got one.
