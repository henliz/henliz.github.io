# playground media

Drop files here and they appear on the desk. Every slot below is already
placed on the canvas — until a file exists the tile shows a dashed outline
with the filename, so you can see exactly where it will land.

Nothing else to edit for these; the names are wired up in `playground.html`
(the `ITEMS` array near the bottom). To move one, change its `x`/`y`.

Any size works — each tile sets its own width and the media scales to it.
`.jpg`, `.png` and `.webp` all work for the image slots; the `.mp4` slot takes
`.mp4`, `.webm` or `.mov` and starts playing on its own, muted and looping.
Just keep the filename.
